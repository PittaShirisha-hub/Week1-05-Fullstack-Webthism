# 🚀 Full Stack Fundamentals Project

A simple Full Stack Application built using React.js, Node.js, and Express.js.

## 📌 Project Overview

This project demonstrates the connection between a React frontend and an Express backend using APIs.

The frontend fetches data from the backend and displays the response dynamically.

---

## 🛠 Technologies Used

- React.js
- Node.js
- Express.js
- JavaScript
- REST API
